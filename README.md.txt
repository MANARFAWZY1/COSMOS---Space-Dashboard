# COSMOS - Space Dashboard

An interactive space explorer dashboard built with vanilla JavaScript and Tailwind CSS.

## 🚀 Live Demo

https://manarfawzy1.github.io/COSMOS---Space-Dashboard/

## ✨ Features

- **Today in Space** - NASA's Astronomy Picture of the Day (APOD), with a date picker to explore any day
- **Upcoming Launches** - the real launch schedule with details for every mission
- **Planet Explorer** - an interactive solar system with physical details for each planet

## 🛠️ Built With

- HTML5
- Tailwind CSS
- Vanilla JavaScript (Fetch API, async/await, DOM manipulation)
- [NASA APOD API](https://api.nasa.gov/)
- [Space Devs Launch Library API](https://thespacedevs.com/)
